ShelfOps 0.7.0-alpha をリリースしました。

**VDIの電源操作**と**英語対応**を追加しました。

---

## 新機能

### セッション一覧からVDIをシャットダウン／再起動

セッションを見ながら、そのセッションが動いているマシンをその場で停止・再起動できます。
Citrix Studio ではマシン一覧に切り替える必要がある操作です。

対象セッションを選び、ツールバーの **「電源操作 ▾」**（または右クリックメニュー）から選びます。

| 操作 | 内容 |
|---|---|
| シャットダウン | OSに正常終了を要求します。**応答しないマシンには効きません** |
| 再起動 | OSに正常終了を要求してから再起動します。同上 |
| **強制電源オフ** | OSに終了処理をさせず電源を切ります。保存されていない作業は失われます |
| **強制リセット** | OSに終了処理をさせず電源を入れ直します。同上 |

強制系は赤字で区切って表示されます。**応答しなくなったVDIを復旧させる**用途では、
正常終了の要求は届かないため強制リセットを使います。

**影響範囲を確認ダイアログに明示します。** この操作の対象はセッションではなく**マシン**なので、
同じマシン上の他のユーザーも巻き添えになります。選択が1件でも、そのマシン上に他のセッションが
あれば「選択したセッションは 1 件ですが、これらのマシン上には合計 5 件のセッションがあります」と
警告します。

**電源操作は「要求を受け付けた」時点で完了と表示されます。** 実際の停止・再起動はハイパーバイザー側で
非同期に進むため、直後に更新してもマシンの状態は変わっていません。しばらく待ってからご確認ください。
電源管理されていないマシン（ホスティング接続に紐づいていない物理端末など）では失敗し、
その理由は「内訳」で確認できます。

### 英語対応

画面・ダイアログ・ログファイルのすべてを英語で表示できるようになりました。

- **初回起動時はWindowsの表示言語で自動的に決まります**（日本語環境なら日本語、それ以外は英語）
- 画面右上の **「言語」** から手動で切り替えられます。**その場で反映**され、ウィンドウを開き直す必要はありません
- 選んだ言語は次回起動時も保持されます
- **ログファイルの文言も選択中の言語で出力されます。** 海外拠点から不具合報告を受ける際、
  英語で出力されたログをそのまま読めます
- 英語版のクイックスタート（`QuickStart.md`）を ZIP に同梱しました

## アップグレード時のご注意

**ZIP 内の 3 つのファイルは必ずセットで差し替えてください。**

```
ShelfOps.exe / ShelfOps.Worker.exe / ShelfOps.Core.dll
```

0.7.0 では電源操作のために内部の通信内容を追加しています。**古いファイルが混在すると
電源操作が動作しません**。フォルダごと入れ替えるのが確実です。

**設定は引き継がれます。** サイト定義は `%APPDATA%\ShelfOps\sites.json` に保存されており、
プログラムのフォルダとは別の場所にあるため、差し替えてもサイトの再登録は不要です。

## ご利用にあたって

- **アルファ版です。** 仕様が予告なく変わることがあり、不具合が含まれる可能性があります
- **電源操作は 0.7.0 の新機能です。まず検証環境の少数のマシンで動作を確認してから**
  本番環境にご利用ください。影響範囲が大きい操作のため、確認ダイアログの内容を必ずご確認ください
- 本ツールはコード署名を行っていないため、初回実行時に Windows SmartScreen の警告が
  表示されることがあります。「詳細情報」→「実行」で起動できます

ShelfOps 0.7.0-alpha is now available. This release adds **VDI power operations** and **English
language support**.

### VDI power operations from the session list

Shut down or restart the machine hosting a session, without switching to the machine list. Select
the sessions and choose an action from **Power ▾** in the toolbar (or the right-click menu):
Shut down, Restart, **Force power off**, **Force reset**. The forced actions are shown in red below
a separator — use Force reset to recover a VDI that has stopped responding, since a graceful request
will not reach a hung OS.

**The confirmation dialog states the full impact.** These operations target the *machine*, not the
session, so other users on the same machine are affected too. Even if you selected one session, you
will see a warning such as "you selected 1 session, but these machines host 5 sessions in total".

**A power operation is reported as done once it has been accepted.** The actual shutdown or restart
happens asynchronously on the hypervisor, so refreshing immediately still shows the old state.
Machines that are not power-managed will fail; use **Details** to see the reason per machine.

### English language support

The whole UI, all dialogs and the log files can now be shown in English.

- **The language follows your Windows display language on first run** (Japanese on a Japanese
  system, English otherwise)
- Switch it manually from **Language** at the top right. The change applies **immediately**
- Your choice is remembered for next time
- **Log files are written in the selected language**, so a log produced at an overseas site can be
  read in English as-is
- An English quick start guide (`QuickStart.md`) is included in the ZIP

### Upgrading

**Replace all three files together**: `ShelfOps.exe`, `ShelfOps.Worker.exe`, `ShelfOps.Core.dll`.
0.7.0 extends the internal protocol for power operations, so **mixing old and new files will break
power operations**. Replacing the whole folder is the safest approach.

**Your settings are preserved.** Site definitions live in `%APPDATA%\ShelfOps\sites.json`, separate
from the program folder, so there is no need to register your sites again.

### Before you use it

This is an alpha release. **Power operations are new in 0.7.0 — verify them on a small number of
machines in a test environment first.** The tool is not code-signed, so SmartScreen may warn on first
run ("More info" → "Run anyway").
