# ShelfOps クイックスタート

**ShelfOps 0.7.0-alpha** — Citrix Virtual Apps and Desktops（オンプレミス）運用管理ツール

このガイドは、はじめて ShelfOps を使うCVAD環境の運用者向けです。サイトの登録から、
マシン・セッションの操作までを順に説明します。

> ⚠ **アルファ版です。** 予告なく仕様が変わることがあり、不具合が含まれる場合があります。
> メンテナンスモード・セッションの切断／ログオフは**実環境に影響します**。
> 本ソフトウェアは無保証です。ご利用は自己責任でお願いします。
> 本ツールは Citrix / Cloud Software Group の**公式製品ではありません**。

> **まず検証環境でお試しください。** 本ツールは書き込み操作（メンテナンスモード切替)を含みます。本番環境での利用は、検証環境で動作を確認したうえで、各組織の運用ルールに従って行ってください。

---

## 1. 動作要件

- **Windows**（10 / 11 / Server 2016 以降）。.NET Framework 4.8 が必要です。
  Windows 10 / 11 には標準搭載です。Windows Server(2016/2019)では .NET Framework 4.8 の追加インストールが必要な場合があります。
- **Citrix Studio がインストールされた管理端末**で実行してください。
  ShelfOps は Citrix の管理コマンド（Broker SDK）を使うため、SDK が入っていない
  PC では動きません（「Citrix SDK が見つかりません」と表示されます）。
- **ドメイン参加済み**で、**Citrix 管理者ロールを持つ AD アカウント**でログオンしていること。
- ローカル管理者権限は**不要**です（標準ユーザーで動作します）。インストールも不要です。
- 動作確認済み環境: Citrix Virtual Apps and Desktops 7 2507 (LTSR) CU1 ＋ Windows 11。他バージョンでは動作未確認です。

---

## 2. 配置と起動

1. 配布された `ShelfOps` フォルダを、管理端末の任意の場所に**フォルダごとコピー**します。
   （インストーラはありません。管理者昇格も不要です。）
2. `ShelfOps.exe` をダブルクリックして起動します。

> 初回起動時、未署名のため Windows SmartScreen の警告が出ることがあります。
> 「詳細情報」→「実行」で起動できます（アルファ版のため未署名です）。

---

## 3. サイトを登録する

管理対象の CVAD サイトを登録します。

1. 画面左下の **「追加」** をクリック。
2. 右側のフォームに入力します。

   | 項目 | 説明 |
   |---|---|
   | ID | サイトを識別する任意の文字列（重複不可。例 `tokyo-prod`） |
   | 表示名 | 画面・ログに出る名前（例 `東京本番サイト`） |
   | プライマリDDC | 最初に接続する Delivery Controller の FQDN（例 `ddc01.corp.example.com`） |
   | 代替DDC | プライマリが応答しないとき順に試す DDC。**1行に1台**。上から順にフェイルオーバー |
   | 認証モード | 「統合Windows認証」または「別の資格情報（接続時に入力）」 |

3. **「保存」** をクリック。設定は `%APPDATA%\ShelfOps\sites.json` に保存されます。
   **パスワードなどの資格情報は保存されません**（接続先の情報のみ）。

複数サイトを登録でき、左の一覧で切り替えられます。

**似た設定のサイトを追加したいときは「複製」が使えます。** サイトを選んで
**「複製」** をクリックすると、DDCの構成と認証モードを引き継いだコピーが元の行の直下に
作られます（IDと表示名は自動で付け直されます）。同じサイトを別の認証モードで登録したい、
DDC構成が似た検証サイトを足したい、といった場合に、FQDNを打ち直す手間と打ち間違いを防げます。
複製したサイトは接続未確認の状態です。内容を直したら **「保存」** してください。

---

## 4. 接続を確認する

1. 一覧でサイトを選び、ツールバーの **「接続テスト」** をクリック。
2. 成功すると、一覧の記号が **○** になり、サイト名・バージョンが表示されます。
   失敗時は理由が表示されます（DDC名の誤り・未到達・権限不足など）。

「全サイト接続テスト」で登録済みの全サイトをまとめて確認できます。

---

## 5. マシンを管理する

1. サイトを選び、ツールバーの **「マシン一覧」** をクリック。
2. 開いたウィンドウで **「更新」** を押すと、マシンの一覧が表示されます
   （メンテ・マシン名・**割り当てユーザー**・カタログ・デリバリーグループ・**種別**・
   登録状態・電源・状態・セッション数）。

**「メンテ」** 列はメンテナンスモードの状態です。ONは**赤い太字**、OFFは薄いグレーで表示され、
一覧の中でも一目で見分けられます。

**「割り当てユーザー」** 列は、そのマシンに割り当てられているユーザーです。
静的割り当て（専有デスクトップ）でのみ値が入ります。
**マルチセッションのマシンでは通常このセルは空です**（異常ではありません）。
ログオン中のユーザーを見たい場合はセッション一覧を使ってください。

**「種別」** はセッションのサポート形態です。
`シングル` はシングルセッションOS（VDI等・1ユーザーが専有）、
`マルチ` はマルチセッションOS（共有デスクトップ／公開アプリ）を表します。

### 絞り込み・検索

ツールバーは2段になっています。上段が操作ボタン、下段が絞り込みです。

- **グループ**: 取得したマシンのデリバリーグループがプルダウンに並びます。
  `(すべて)` で全件、`(未所属)` でデリバリーグループ未割り当てのマシンだけを表示します。
- **カタログ**: 同様に、マシンカタログで絞り込めます。
- **種別**: `シングルセッション` / `マルチセッション` で絞り込めます。
- **メンテ**: メンテナンスモードの `ON` / `OFF` で絞り込めます。
- **検索**: マシン名・DNS名・**割り当てユーザー**の**部分一致**で検索します
  （大文字小文字は区別しません）。ユーザー名を入れれば、その人の専有マシンを探せます。
- これらは同時に指定できます。右下に「表示 N 台 / 全 M 台」が出ます。
- 絞り込みは取得済みデータに対して行うため、変更しても再取得は発生しません。

### メンテナンスモードの切替（変更操作）

**複数のマシンをまとめて切り替えられます。**

1. 対象マシンを選択します。**Ctrl+クリック**で個別に追加、**Shift+クリック**で範囲選択。
2. **「メンテナンス ON」** または **「メンテナンス OFF」** をクリック
   （一覧の右クリックメニューからも実行できます）。
3. 確認ダイアログに**対象の件数**が出ます。内容を確認して「はい」。
4. 切替後、一覧が自動更新され、「メンテ」列の表示が変わります。

**一部だけ失敗した場合**（権限やマシンの状態によって起こります）、処理は途中で止まらず
最後まで実行され、「成功 N 台 / 失敗 M 台」と表示されます。
画面右下の **「内訳」** ボタンを押すと、**どのマシンが失敗したか・その理由**を確認できます。
内訳は「一覧をコピー」ボタンでそのまま Excel に貼り付けられます。

### 一覧を書き出す（CSV / Excel）

棚卸しや報告のために、一覧をファイルやクリップボードに出せます。

- **「Excelへコピー」**: タブ区切りでクリップボードにコピーします。
  Excel を開いて貼り付けるだけで表になります。**普段はこちらが手早いです。**
- **「CSV保存...」**: CSVファイルとして保存します。
  文字コードは UTF-8（BOM付き）なので、Excel で開いても日本語が化けません。

対象は **行を選択していればその行だけ、選択していなければ表示中（絞り込み後）の全行**です。
書き出しには、画面には出していない **DNS名** も含まれます。

> 一覧の**行を選んで Ctrl+C** でも、その行を見出し付きでコピーできます。
> 数行だけ手早く控えたいときに便利です。

## 6. セッションを管理する

1. サイトを選び、ツールバーの **「セッション一覧」** をクリック。
2. **「更新」** で、ログオン中のセッション一覧が表示されます
   （ユーザー・マシン・デリバリーグループ・状態・クライアント・開始時刻・状態変更時刻）。

「状態変更時刻」は、セッションの状態が最後に変わった時刻です
（例: いつから切断されたままかの判断に使えます）。

### 絞り込み・検索

- **グループ**: 取得したセッションのデリバリーグループをプルダウンから選べます。
- **状態**: `Active`（接続中）/ `Disconnected`（切断済み）で絞り込めます。
  **切断されたまま放置されているセッションを探す**のに使います。
- **検索**: ユーザー名・マシン名の**部分一致**で検索します
  （`CLUser` のように一部だけでも探せます。大文字小文字は区別しません）。
- 右下に「表示 N 件 / 全 M 件」が出ます。

### 切断・ログオフ（破壊的操作）

> ⚠ これらは**エンドユーザーのセッションに影響します**。特にログオフは
> **保存されていない作業が失われます**。対象をよく確認してください。

**複数のセッションをまとめて操作できます。**

1. 対象セッションを選択します。**Ctrl+クリック**で個別に追加、**Shift+クリック**で範囲選択。
2. **「切断」**（セッションを切断）または **「ログオフ」**（セッションを終了）をクリック
   （一覧の右クリックメニューからも実行できます）。
3. 確認ダイアログに**対象の件数**と対象ユーザーが出ます。内容を確認して「はい」。
4. 実行後、一覧が自動更新されます。

マシン一覧と同様、一部だけ失敗しても処理は止まらず、
**「内訳」** ボタンでどのセッションが失敗したかを確認できます。

### VDIのシャットダウン・再起動（電源操作）

> ⚠ **この操作の対象は「セッション」ではなく「マシン」です。**
> 選んだセッションが動いているマシンごと停止するため、**同じマシン上の他のユーザーも巻き添えになります。**

Citrix Studio ではマシン一覧を開き直さないとできない操作を、セッションを見ながらその場で実行できます。

1. 対象セッションを選択します。
2. ツールバーの **「電源操作 ▾」**（または一覧の右クリックメニュー）から選びます。

   | 操作 | 内容 |
   |---|---|
   | シャットダウン | OSに正常終了を要求します。**応答しないマシンには効きません** |
   | 再起動 | OSに正常終了を要求してから再起動します。同上 |
   | **強制電源オフ** | OSに終了処理をさせず電源を切ります。保存されていない作業は失われます |
   | **強制リセット** | OSに終了処理をさせず電源を入れ直します。同上 |

   強制系は赤字で区切って表示されます。**応答しなくなったVDIを復旧させたい場合**は強制リセットを使います。

3. 確認ダイアログで**影響範囲**を確認します。選択したセッションが1件でも、そのマシン上に他のセッションがあれば
   「選択したセッションは1件ですが、これらのマシン上には合計5件のセッションがあります」と警告が出ます。
4. 「はい」で実行します。

**電源操作は要求を受け付けた時点で完了と表示されます。** 実際の停止・再起動はハイパーバイザー側で
進むため、直後に「更新」してもマシンの状態はまだ変わっていません。しばらく待ってから確認してください。

**電源管理されていないマシン**（ホスティング接続に紐づいていない物理端末など）では失敗します。
その場合は「内訳」ボタンで対象ごとの理由を確認できます。

---

### 一覧を書き出す（CSV / Excel）

マシン一覧と同じく **「Excelへコピー」** と **「CSV保存...」** が使えます。
対象は行を選択していればその行だけ、選択していなければ表示中の全行です。
書き出しには、画面には出していないセッションの **Uid** も含まれます。

## 7. 別の資格情報で接続する

現在ログオンしているアカウントとは別の AD アカウントで操作したい場合:

1. サイトの認証モードを **「別の資格情報（接続時に入力）」** にして保存します。
2. 接続テストや各操作の実行時に、資格情報の入力ダイアログが出ます。
3. 入力したアカウントで対象 DDC に接続します。

- 入力内容は**保存されません**（ディスクに書かれません）。
- マシン一覧・セッション一覧のウィンドウを開いている間は、そのウィンドウ内で
  資格情報を保持し、閉じると破棄します。
- 指定したアカウントは**ネットワーク認証にのみ**使われます。パスワードの誤りは
  接続時に認証エラーとして分かります。

---

## 8. ログ

- すべての操作は `%APPDATA%\ShelfOps\logs\` にログとして残ります
  （特にメンテナンス切替・切断・ログオフは監査記録として重要）。
- ツールバーの **「ログフォルダ」** ボタンで開けます。
- ログには接続先 DDC・マシン名・ユーザー名などの管理情報が含まれます。
  外部へ共有する際はご注意ください。

## 9. よくある質問・トラブル

**Q. 「Citrix SDK が見つかりません」と出る**
→ Citrix Studio が入っていない PC で実行しています。**管理端末で実行**してください。

**Q. 接続テストが失敗する**
→ DDC の FQDN が正しいか、その DDC に到達できるか、ログオン中のアカウントに
Citrix 管理者ロールがあるかを確認してください。「不十分な管理者権限」は認可の問題です。

**Q. 起動時に SmartScreen の警告が出る**
→ アルファ版のため未署名です。「詳細情報」→「実行」で起動できます。

**Q. メンテナンス切替やログオフが「不十分な管理者権限」で失敗する**
→ そのアカウントに必要な Citrix 管理者ロールがありません。適切なロールのアカウントで
実行するか、「別の資格情報」モードで権限のあるアカウントを指定してください。

## 10. 既知の制限（アルファ版）

- **シャドウ（画面共有）は未対応**です。
- 対象はオンプレミスの Citrix Virtual Apps and Desktops です。
- 現時点の操作範囲: 接続確認 / マシン一覧・メンテナンスモード /
  セッション一覧・切断・ログオフ・電源操作 / 一覧の書き出し（CSV・クリップボード）。
- 電源操作は**電源管理されているマシン**（ホスティング接続に紐づくマシン）のみ対象です。
- 書き出し形式は CSV とタブ区切り（クリップボード）です。xlsx の直接出力には対応していません
  （CSVを Excel で開いて保存し直してください）。
- アプリは**未署名**です。正式な証明書を導入するまでは、起動時に
  Windows SmartScreen の警告が出ることがあります。

## 11. 表示言語を切り替える

ShelfOps は日本語と英語に対応しています。

- **初回起動時はWindowsの表示言語で自動的に決まります**（日本語環境なら日本語、それ以外は英語）。
- 画面右上の **「言語」** から手動で切り替えられます。切り替えは**その場で反映**され、
  ウィンドウを開き直す必要はありません。
- 選んだ言語は次回起動時も保持されます（`%APPDATA%\ShelfOps\ui-state.json`）。
- ログファイルの文言も選択中の言語で出力されます。海外拠点から不具合報告を受ける場合、
  英語で出力されたログをそのまま読めます。
