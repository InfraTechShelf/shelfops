ShelfOps 0.9.0-alpha をリリースしました。

**デリバリーグループ設定のスナップショット（採取・保存・比較）**と、**マシン一覧からの電源操作**を
追加しました。スナップショットは読み取りのみで、環境を変更しません。

---

## 新機能

### デリバリーグループ設定の採取・保存・比較

デリバリーグループ一覧で1グループを選び、**「設定を採取」** をクリックすると、そのグループの設定を
丸ごと取得して表で表示します。

- グループ本体の全プロパティ（タグを含む）
- アクセスポリシー、権利付与（デスクトップ／アプリ）、割り当て（専有）
- 公開アプリケーション、電源スケジュール、再起動スケジュール

**「ファイルに保存...」** で JSON ファイルに保存でき、あとで **「保存ファイルと比較...」** を使うと、
保存時点から何が変わったかを一覧できます。

- 差分は「変更」「保存時のみ」「現在のみ」「比較不可」に分けて色付きで表示します。
  配列の並び順だけの違いは既定で隠します
- 対象は**名前**で対応付けます。作り直されて内部番号が変わった対象も同じものとして比較されます
- マシン数・セッション数などの**稼働状況は比較しません**（保存はします）。
  「設定は変わっていないのに差分だらけ」にならないようにしています
- 権限不足などで**取得できなかった区分は「0件」と区別**して赤字で示し、比較では「比較不可」にします。
  「消えた」と誤解させないためです
- 別のグループ・別のサイトのファイルと比較すると、赤字で注意を出します

変更作業の前後の記録や、「いつの間にか設定が変わっていた」の確認に使えます。

**今回は比較までです。保存ファイルから設定を戻す（復元する）機能は次のバージョン以降で追加します。**
設計はリポジトリの `docs/SPEC_phase5_deliverygroups.md` にあります。

> 保存ファイルにはユーザー／グループ名と SID、マシン名、アプリの実行パスなどが含まれます
> （資格情報は含みません）。ログと同様、共有する際は内容をご確認ください。

### マシン一覧からの電源操作

マシン一覧で、選択したマシンの**シャットダウン・再起動・強制電源オフ・強制リセット**ができるように
なりました。操作はセッション一覧のものと同じです。

セッションが無いマシン（未登録・停止中・誰もログオンしていない）はセッション一覧に出ないため、
これまで ShelfOps からは操作できませんでした。デリバリーグループ一覧で未登録のマシンを見つけ、
マシン一覧で再起動して登録し直させる、という流れが ShelfOps の中で完結します。

確認ダイアログには、止めるマシンの台数と、**影響を受けるセッションの数**が表示されます。

## アップグレード時のご注意

**ZIP 内の 3 つのファイルは必ずセットで差し替えてください。**

```
ShelfOps.exe / ShelfOps.Worker.exe / ShelfOps.Core.dll
```

0.9.0 では設定の採取のために内部の通信内容を追加しています。古いファイルが混在すると
新機能が動作しません。フォルダごと入れ替えるのが確実です。

**設定は引き継がれます。** サイト定義は `%APPDATA%\ShelfOps\sites.json` に保存されており、
プログラムのフォルダとは別の場所にあるため、差し替えてもサイトの再登録は不要です。

## ご利用にあたって

- **アルファ版です。** 仕様が予告なく変わることがあり、不具合が含まれる可能性があります
- 設定の採取は、CVAD のバージョンによってはコマンドレットやプロパティが異なる場合があります。
  取得できなかった区分は赤字で理由を表示しますので、その場合は [Issues](../../issues) で
  お知らせいただけると助かります
- 本ツールはコード署名を行っていないため、初回実行時に Windows SmartScreen の警告が
  表示されることがあります。「詳細情報」→「実行」で起動できます
- ShelfOps は Apache License 2.0 のオープンソースです。ソース: https://github.com/InfraTechShelf/shelfops

ShelfOps 0.9.0-alpha is now available. This release adds **delivery group configuration snapshots
(capture, save and compare)** and **power operations in the machine list**. Snapshots are read-only
and do not change your environment.

### Delivery group configuration: capture, save and compare

Select a group in the delivery group list and click **Capture settings** to read its complete
configuration and show it as a table:

- every property of the group itself (including tags)
- access policy rules, desktop and application entitlements, assignment rules
- published applications, power time schemes, reboot schedules

**Save to file...** writes it as JSON. Later, **Compare with saved file...** shows what has changed
since then.

- Differences are grouped as Changed / Only in saved / Only in current / Not comparable and
  colour-coded. Differences in array order only are hidden by default
- Targets are matched **by name**, so an object that was re-created with a new internal ID still
  lines up
- **Runtime status (machine and session counts) is not compared** (it is still saved), so an
  unchanged configuration does not show a wall of differences
- **Sections that could not be read** (for example, missing permissions) are shown in red and kept
  distinct from "none"; in a comparison they are "Not comparable" rather than "deleted"
- Comparing against a file from a different group or site shows a red warning

Use it to record a group before and after a change, or to find out what changed without anyone
telling you.

**This release compares only. Restoring a saved configuration will come in a later release.**
The design is in `docs/SPEC_phase5_deliverygroups.md`.

> Saved files contain user and group names and SIDs, machine names and application paths (never
> credentials). Treat them like log files and check the content before sharing.

### Power operations in the machine list

The machine list can now **shut down, restart, force power off and force reset** the selected
machines - the same operations as in the session list.

Machines without sessions (unregistered, powered off, or with nobody logged on) never appear in the
session list, so ShelfOps could not act on them before. Now you can find unregistered machines in the
delivery group list and restart them from the machine list without leaving ShelfOps.

The confirmation shows how many machines will be affected and **how many sessions will be lost**.

### Upgrading

**Replace all three files together**: `ShelfOps.exe`, `ShelfOps.Worker.exe`, `ShelfOps.Core.dll`.
0.9.0 extends the internal protocol for configuration capture, so mixing old and new files will
break the new feature. Your settings in `%APPDATA%\ShelfOps\` are preserved.

Cmdlets and properties can differ between CVAD versions. If a section shows up in red as
"could not be read", please let us know in [Issues](../../issues).
