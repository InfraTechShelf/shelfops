ShelfOps 0.6.0-alpha をリリースしました。

本番環境でいただいたフィードバックへの対応版です。**一覧の書き出し**、**複数選択での一括操作**、**絞り込みの拡充**を中心に、要望として挙がっていた 9 項目すべてを実装しました。

---

## 新機能

### 一覧の書き出し（CSV / Excel）

マシン一覧・セッション一覧を、棚卸しや報告のために書き出せるようになりました。

- **「Excelへコピー」**: タブ区切りでクリップボードにコピーします。Excel に貼り付けるだけで表になります
- **「CSV保存...」**: CSV ファイルとして保存します。UTF-8（BOM 付き）なので Excel で開いても文字化けしません
- 対象は、**行を選択していればその行だけ、選択していなければ表示中（絞り込み後）の全行**です
- 一覧の行を選んで **Ctrl+C** でも、見出し付きでコピーできます
- 書き出しには、画面には表示していない項目（マシンの DNS 名、セッションの Uid）も含まれます

### 複数選択での一括操作

**Ctrl+クリック**／**Shift+クリック**で複数の対象を選び、まとめて実行できます。

- マシン: メンテナンスモードの ON / OFF
- セッション: 切断 / ログオフ
- 確認ダイアログには**対象の件数**が表示されます
- **一部の対象が失敗しても処理は止まらず、最後まで実行されます**（権限やマシンの状態によって一部だけ失敗することがあるため）
- 実行後に表示される **「内訳」** ボタンから、**どの対象がなぜ失敗したか**を確認できます。内訳はそのまま Excel に貼り付けられる形でコピーできます

### 絞り込みの追加

- マシン一覧: **カタログ**、**メンテナンスモード（ON / OFF）** で絞り込めるようになりました
- セッション一覧: **セッション状態（Active / Disconnected）** で絞り込めるようになりました

「切断されたまま放置されているセッションを探してログオフする」といった運用がしやすくなっています。

### 割り当てユーザー列（マシン一覧）

静的割り当て（専有デスクトップ）のマシンが誰に割り当てられているかを、一覧で確認できるようになりました。検索欄からユーザー名で引くこともできます。

マルチセッションのマシンでは通常このセルは空欄になりますが、異常ではありません（ログオン中のユーザーはセッション一覧で確認できます）。

### サイト設定の複製

登録済みのサイトを、DDC の構成ごと複製できるようになりました。同じサイトを別の認証モードで登録したい場合や、構成の似た検証用サイトを追加したい場合に、FQDN を打ち直す手間と打ち間違いを防げます。

## 変更点

### メンテナンスモードの表示を変更しました

- 従来: チェックボックス
- 0.6.0: **「ON」「OFF」の文字**（ON は赤い太字で表示）

複数選択に対応したことで、チェックボックスが「行の選択」を表すのか「メンテナンスモードの状態」を表すのか紛らわしくなったためです。**チェックによる選択は行の選択に一本化**し、メンテナンスモードの状態は文字と色で示すようにしました。

### ツールバーが 2 段になりました

上段が操作ボタン、下段が絞り込みです。絞り込み条件が増えたため、役割で分けています。

### 右クリックメニューを追加しました

一覧を右クリックすると、書き出しと操作をその場で実行できます。

---

## 内部的な改善

- 一括操作は**対象をまとめて 1 回で処理**する方式にしました。1 台ずつ処理すると Citrix SDK の読み込みが台数分繰り返され、台数に比例して時間がかかるためです
- 一括操作のタイムアウトを、対象件数に応じて自動的に延長するようにしました
- 通信が失敗した際に、書き込み操作が二重に実行されないよう対策しました
- 操作の結果は、対象ごとの成否を含めてログファイルに記録されます（監査記録）

## アップグレード時のご注意

**ZIP 内の 3 つのファイルは必ずセットで差し替えてください。**

```
ShelfOps.exe / ShelfOps.Worker.exe / ShelfOps.Core.dll
```

0.6.0 では内部の通信内容が変わっているため、**古いファイルが混在すると一括操作が動作しません**。フォルダごと入れ替えるのが確実です。

**設定は引き継がれます。** サイト定義は `%APPDATA%\ShelfOps\sites.json` に保存されており、プログラムのフォルダとは別の場所にあるため、差し替えてもサイトの再登録は不要です。

## ご利用にあたって

- **アルファ版です。** 仕様が予告なく変わることがあり、不具合が含まれる可能性があります
- **一括操作は 0.6.0 の新機能です。まず少数の対象で動作を確認してから、多数の対象に適用してください。** 一度に影響する範囲が広がるため、確認ダイアログの対象件数を必ずご確認ください
- 本番環境でのご利用は、検証環境で動作を確認したうえで、各組織の運用ルールに従ってお願いします
- 本ツールはコード署名を行っていないため、初回実行時に Windows SmartScreen の警告が表示されることがあります。「詳細情報」→「実行」で起動できます
