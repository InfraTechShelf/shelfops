ShelfOps 0.7.1-alpha をリリースしました。

**このバージョンから ShelfOps はオープンソース（Apache License 2.0）です。**

機能は 0.7.0-alpha と同じです。変更はライセンスと配布物の中身に関するものだけです。

---

## 変更点

- **ソースコードを公開しました。** https://github.com/InfraTechShelf/shelfops
  Citrix 管理者権限で動くツールが実際に何をしているかを確認でき、Windows と無償の
  Visual Studio Build Tools だけで自分でビルドできます（`BUILDING.md`）。
  NuGet 依存はなく、Citrix のバイナリも含みません
- **ライセンスを Apache License 2.0 にしました。** 商用環境を含めて自由に利用でき、改変・再配布も
  ライセンスの条件のもとで行えます。以前の「再配布・改変の禁止」は撤回します
- ZIP に `LICENSE` と `NOTICE` を同梱しました
- バージョン情報ダイアログにライセンスとソースコードの URL を表示するようにしました

## アップグレード

0.7.0-alpha からの機能変更はありません。ZIP 内の 3 ファイル（`ShelfOps.exe` / `ShelfOps.Worker.exe` /
`ShelfOps.Core.dll`）をフォルダごと差し替えてください。設定（`%APPDATA%\ShelfOps\`）はそのまま引き継がれます。
