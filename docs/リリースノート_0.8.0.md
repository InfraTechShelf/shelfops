ShelfOps 0.8.0-alpha をリリースしました。

**ライセンス情報の表示**と**デリバリーグループ一覧**を追加しました。どちらも読み取りのみで、
環境を変更する操作は含みません。

---

## 新機能

### 接続テストにライセンス情報を表示

接続結果に、サイトのライセンス構成と**ライセンスサーバーとの接続状況**が出るようになりました。

- ライセンスサーバー名・ポート、製品（XDT / MPS）、エディション、ライセンスモデル（UserDevice / Concurrent）
- **DDC ごとの接続状況。** 「DDC-02 だけライセンスサーバーに繋がっていない」という状況は実際に起きるため、
  サイトで1行にまとめず、コントローラ単位で並べています。OK 以外は `**` で目立たせます
- **猶予期間中は警告を出します。** ライセンスサーバーと通信できていない状態で、猶予が切れると
  新規セッションが拒否されます。接続テストが成功していても先に気づくべき状態なので、
  サイト一覧の状態欄にも「⚠ ライセンス要確認」を付けます

新しいコマンドレットは使っていません。従来の接続テストが呼んでいる `Get-BrokerSite` /
`Get-BrokerController` から取り出しているだけなので、権限要件も所要時間も変わりません。

### デリバリーグループ一覧

ツールバーの **「デリバリーグループ」** から、サイト内のデリバリーグループを一覧できます
（名前・有効・メンテ・種別・配信・セッション種別・マシン数・使用中・未登録・セッション数・説明）。

- **未登録のマシンがあるグループは赤字**で表示します。VDA が DDC に登録できていない状態で、
  「起動できない」「接続できない」の主因です
- 無効なグループも赤字で表示します
- 絞り込み（種別・配信・有効／無効・名前）と書き出し（CSV／Excelへコピー）はマシン一覧と同じです

この画面は 0.8 では読み取り専用です。**デリバリーグループの設定を保存し、保存時点と比較し、
復元する**機能を、この画面を起点に次のバージョン以降で追加していきます。設計は
リポジトリの `docs/SPEC_phase5_deliverygroups.md` にあります。

## アップグレード時のご注意

**ZIP 内の 3 つのファイルは必ずセットで差し替えてください。**

```
ShelfOps.exe / ShelfOps.Worker.exe / ShelfOps.Core.dll
```

0.8.0 ではデリバリーグループ一覧のために内部の通信内容を追加しています。古いファイルが混在すると
新機能が動作しません。フォルダごと入れ替えるのが確実です。

**設定は引き継がれます。** サイト定義は `%APPDATA%\ShelfOps\sites.json` に保存されており、
プログラムのフォルダとは別の場所にあるため、差し替えてもサイトの再登録は不要です。

ShelfOps 0.8.0-alpha is now available. This release adds **licensing information** to the connection
test and a **delivery group list**. Both are read-only; nothing in this release changes your environment.

### Licensing information in the connection test

The connection result now shows the site's licensing configuration and **the license server
connection state of each DDC**.

- License server name and port, product (XDT / MPS), edition, licensing model (UserDevice / Concurrent)
- **Per-DDC connection state.** "Only DDC-02 cannot reach the license server" happens in practice, so
  the state is listed per controller rather than summarised per site. Anything other than OK is
  marked with `**`
- **A warning when the site is in a grace period.** That means the license server cannot be reached,
  and new sessions will be refused once the grace period expires - something to act on even though
  the connection test itself succeeded. The site list also shows "⚠ Check licensing"

No new cmdlets are involved; the values come from the `Get-BrokerSite` / `Get-BrokerController` calls
the connection test already makes, so permissions and timing are unchanged.

### Delivery group list

**Delivery groups** in the toolbar lists the site's delivery groups (name, enabled, maintenance, kind,
delivery type, session support, machines, in use, unregistered, sessions, description).

- **Groups with unregistered machines are shown in red.** Unregistered VDAs are the usual cause of
  "I can't launch" / "I can't connect" calls
- Disabled groups are shown in red as well
- Filters (kind, delivery type, enabled/disabled, name) and export (CSV / Copy for Excel) work exactly
  as in the machine list

This view is read-only in 0.8. **Saving a delivery group's configuration, comparing it with a saved
copy, and restoring it** will be built on top of this view in the following releases. The design is in
`docs/SPEC_phase5_deliverygroups.md`.

### Also fixed

- The "Auth" line and the summary line of the connection result were still in Japanese when the UI
  language was English.

### Upgrading

**Replace all three files together**: `ShelfOps.exe`, `ShelfOps.Worker.exe`, `ShelfOps.Core.dll`.
0.8.0 extends the internal protocol for the delivery group list, so mixing old and new files will
break the new feature. Your settings in `%APPDATA%\ShelfOps\` are preserved.
