# ShelfOps

**Citrix Virtual Apps and Desktops 対応 運用管理コンソール（非公式ツール）**

ShelfOps は、Citrix Virtual Apps and Desktops（CVAD）環境のマシン確認・メンテナンスモード切替・セッション管理を、Studio を開かずに行える無料の Windows GUI ツールです。**端末にローカル管理者権限を与えずに配布・利用できる**設計が特徴です。

運営サイト: [Infra Tech Shelf](https://infratechshelf.com/)（設計思想の解説記事あり）

> **アルファ版です。** 仕様が予告なく変わることがあり、不具合が含まれる可能性があります。
> メンテナンスモード切替・セッションの切断／ログオフは実環境に影響します。
> **必ず検証環境で動作を確認してからご利用ください。**

---

## 主な機能

| 機能 | 内容 |
|---|---|
| 接続テスト | Delivery Controller への接続確認・フェイルオーバー対応 |
| マシン一覧 | サイト内マシンの一覧・状態確認。割り当てユーザーも表示 |
| メンテナンスモード切替 | 複数マシンをまとめて ON/OFF（実行前に対象件数を示す確認ダイアログを表示） |
| セッション管理 | セッションの一覧・切断・ログオフ。複数選択で一括操作 |
| 絞り込み・検索 | デリバリーグループ／カタログ／種別／メンテ状態／セッション状態で絞り込み。名前の部分一致検索 |
| 一覧の書き出し | CSV 保存と、Excel へ貼り付けられる形でのクリップボードコピー（棚卸し・報告用） |
| サイト設定の複製 | 登録済みサイトを DDC 構成ごとコピー。似た設定のサイトを打ち直さずに追加できます |
| 統合認証 / 別資格情報 | 現在のユーザーでの接続に加え、別アカウントの資格情報を指定した接続に対応 |
| 高速動作 | 接続の常駐化により、2 回目以降の操作は 0.1〜0.3 秒程度で応答（実測。初回のみ約 3 秒） |

### 設計上の特徴

- **標準ユーザーで動作**: ローカル管理者権限のないドメインユーザーで全機能が動作します。運用担当者の端末に特権を配る必要がありません
- **資格情報の分離**: 接続は資格情報ごとに独立したワーカープロセスで実行されます。別資格情報のパスワードはファイルやログに書き出しません
- **書き込み操作は確認必須**: 環境を変更する操作（メンテナンスモード切替、セッションの切断・ログオフ）は必ず確認ダイアログを挟みます。複数選択時は対象件数を明示します
- **一括操作の結果が追える**: 一部の対象だけ失敗しても処理は止まらず最後まで実行され、**どの対象がなぜ失敗したか**を画面とログの両方で確認できます
- **監査記録が残る**: 操作の内容と結果はログファイル（`%APPDATA%\ShelfOps\logs\`）に記録されます

### 現バージョンでできないこと

- セッションのシャドウ（画面共有）— 今後のバージョンで対応予定
- マシンの電源管理操作 — 今後のバージョンで対応予定
- デリバリーグループ・カタログの管理 — 検討中
- **Citrix Cloud（DaaS）には対応しません。オンプレミス環境専用です**

## 動作要件

- **Windows**（10 / 11 / Server 2016 以降）。
- .NET Framework 4.8 が必要です。
  Windows 10 / 11 には標準搭載です。Windows Server(2016/2019)では .NET Framework 4.8 の追加インストールが必要な場合があります。
- **Citrix Studio がインストールされた管理端末**で実行してください。
  ShelfOps は Citrix の管理コマンド（Broker SDK）を使うため、SDK が入っていない
  PC では動きません（「Citrix SDK が見つかりません」と表示されます）。
- **ドメイン参加済み**で、**Citrix 管理者ロールを持つ AD アカウント**でログオンしていること。
- ローカル管理者権限は**不要**です（標準ユーザーで動作します）。インストールも不要です。
- 動作確認済み環境: Citrix Virtual Apps and Desktops 7 2507 (LTSR) CU1 ＋ Windows 11。他バージョンでは動作未確認です。

## インストール

1. [Releases](https://github.com/InfraTechShelf/shelfops/releases/) から最新版の zip をダウンロード
2. 展開前に、zip ファイルの SHA-256 ハッシュが下記および Release ページの記載と一致することを確認してください

   ```
   SHA-256: b4b9b688ce07fe872c7ca41ca1f48f7f56902852a523a24eac24a003b217c978
   ```

   確認コマンド（PowerShell）:

   ```powershell
   Get-FileHash -Algorithm SHA256 .\ShelfOps-0.6.0-alpha.zip
   ```

3. 任意のフォルダーに展開し、`ShelfOps.exe` を実行（インストーラーはありません。レジストリも変更しません）

> **SmartScreen の警告について**: 本ツールはコード署名を行っていないため、初回実行時に Windows SmartScreen の警告が表示されることがあります。「詳細情報」→「実行」で起動できます。ハッシュ照合で改ざんがないことを確認のうえ、ご判断ください。

## はじめての方へ

**まず検証環境でお試しください。** 本ツールは書き込み操作（メンテナンスモード切替、セッションの切断・ログオフ）を含みます。本番環境での利用は、検証環境で動作を確認したうえで、各組織の運用ルールに従って行ってください。

**複数選択での一括操作は特にご注意ください。** 一度に多数のマシン・セッションへ影響するため、実行前に確認ダイアログの対象件数を必ずご確認ください。まずは少数の対象で動作を確かめることをおすすめします。

操作手順の詳細はZIPファイル内の クイックスタート.md をご覧ください
